# Booth Compass

**Plan any expo in minutes — without telling anyone why you're there.**

**Live demo:** https://aj5749843-cmd.github.io/booth-compass/ (desktop Chrome with Gemini Nano for on-device mode)

Big expos have hundreds of booths and a floor plan that shows names, not reasons. Today visitors paste the exhibitor list into a cloud chatbot together with their real goals: the budget, the vendor they want to replace, the job they are quietly hunting. Booth Compass does the same job, but the personal part never leaves the laptop.

## How the hybrid split works

| Task | Where it runs | Why |
|---|---|---|
| Turn the messy public exhibitor directory into clean booth cards | **Cloud** (Gemini, `ONLY_IN_CLOUD`), once per expo | Heavy, one-time, public data only |
| Read the visitor's private goals into a compact profile | **On device** (Gemini Nano, `PREFER_ON_DEVICE` / `ONLY_ON_DEVICE`) | Personal and sensitive |
| Score every booth against that profile (60+ calls) | **On device** | Private, free per call, works offline |
| 30-second spoken briefing + 3 questions to ask the exhibitor | **On device** | Personal; questions are written so they don't reveal the budget |

- **Privacy shield** (on by default) forces personal tasks to `ONLY_ON_DEVICE`. With it off, the app falls back to the cloud on browsers without Gemini Nano.
- **"What left my device?"** lists every AI call, where it ran, and the exact text sent to the cloud, if any.
- The expo pack is cached locally, so after the one cloud step the planner works with the network switched off.

All AI calls go through the **Firebase AI Logic** web SDK (`firebase/ai`, hybrid inference) — see `src/ai.js`.

## Run it

```bash
npm install
npm run dev
```

Without Firebase settings the app runs in **simulation mode** so the interface can be explored.

To use real AI:
1. Create a Firebase project and a Web app; paste its config into `src/config.js`.
2. Enable **Firebase AI Logic** with the Gemini Developer API.
3. Enable **App Check** with reCAPTCHA Enterprise and paste the site key into `src/config.js`. For localhost, the app sets a debug token; register it in the console.
4. Use desktop Chrome 139+ and enable `chrome://flags/#prompt-api-for-gemini-nano-multimodal-input`, then click **Enable on-device AI** once to download Gemini Nano.

## Deploy

`npm run build` writes the static site to `docs/`, which GitHub Pages serves (Settings → Pages → branch `main`, folder `/docs`).
